# Calculator Project

A simple and user-friendly calculator built using HTML, CSS, and JavaScript.

## Features

- Addition
- Subtraction
- Multiplication
- Division
- Simple and clean user interface
- Interactive calculator buttons

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Project Files

- `calculator.html` – Structure of the calculator
- `calculator.css` – Styling and design
- `calculator.js` – Calculator functionality

## How to Run

1. Download or clone this repository.
2. Open `calculator.html` in your web browser.
3. Start using the calculator.
